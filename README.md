# 🎓 SchoolBuddy - AI Study Assistant

A school-themed AI chatbot powered by Google Gemini API that helps students with homework, concepts, and study tips.

## Features

- 🤖 AI-powered chat using Gemini 2.0 Flash
- 🏫 School-themed UI with subject quick-access buttons
- 📱 Fully responsive design
- 💬 Markdown support in bot replies
- 🔄 Session-based chat history
- ✨ Beautiful animations and modern design

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Add your Gemini API key:**
   Edit the `.env` file and replace `your_gemini_api_key_here` with your actual API key.

3. **Start the server:**
   ```bash
   npm start
   ```

4. **Open in browser:**
   Go to [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Backend:** Node.js, Express
- **AI:** Google Gemini 2.0 Flash API
